## 一、一句话结论

本次不是"补文件"，而是**按论文 Methods 的定义重建发表侧口径**：把旧归档里"含重复行的分数权重"换成**严格分式计数** `author_count / total_authors`，记录集同步改为**跨源去重后的 49,189**。主结论方向不变，但一批分国发表量及其派生数值会变（旧→新见 §四），其中"全球第一产出国的变化"和"人均强度 28×→约 7×"需要改正文叙述。

## 二、为什么要改

2026-10-26 的作者侧数值核查（`human input/fll20261026/稿件数值核查报告(1).md`）发现：归档数据里**同时存在两套发表口径**——

| 口径 | 来源 | 合计 | 性质 |
|---|---|---|---|
| A（旧，稿件所用） | `明细_作者贡献_分数` → `nine_class_195.csv::publications_total` | **47,006.3** | 该表 **87,901 行只对应 38,218 个记录，含 9,286 条整行重复**，重复贡献被再次累计 |
| B（新，方法口径） | `frac(record,country) = author_count / total_authors`，限定语料 33,145 | **32,647.3** | 每篇对全部国家合计 ≤ 1；`(record,country)` 唯一 |

判定旧口径不成立的三条硬证据：

1. **总量越界**：47,006.3 > 语料 33,145。分式计数下"每篇合计 ≤ 1"，总量不可能超过记录数。
2. **单国越界**：旧表给中国 9,642.3；而同一权重表按"每篇给每个国家记 1"的全量计数上限只有 7,085。
3. **行级重复**：87,901 行 − 38,218 记录 = 9,286 行重复（按记录/国家/作者数整行重复）。

结论：**稿件侧与旧归档侧各自自洽，但不能同时正确**。按"方法优先"原则，保留 Methods 已声明的方法（fractional counting），修改数值；旧口径与旧文件不再随档发布。

## 五、对结论的影响

**方向不变**：全球自然档案证据在采样与发表两侧都高度不平等；HH 国家在两侧同时主导；高收入国家发表份额远高于其采样份额；"能力差距（capacity gap）而非采样差距"的解读不变。

**需要改写的具体断言**：

1. **第一产出国由"中国"改为"美国"**：5,657 vs 5,324。凡以"中国第一/中国领先"开头的句子、图注、摘要句均需改；中国仍居第二。
2. **不平等强度**：HH 发表份额 89.11 → 88.97（−0.14 pp），但采样份额 81.29 → 80.53（−0.76 pp），**盈余（发表−采样）7.8 → 8.44 pp 扩大 0.64 pp**，"发表比采样更集中"的证据更强。
3. **零发表与双零国家数**：零发表 42 → **51**，双零 39 → **47**；MM 类 39 → **37**。旧稿把"双零 39"与"MM 39 国亏空 7.2 pp"混用，新稿必须分开："双零 47 国"、"MM 37 国亏空 −7.06 pp"。
4. **相关强度**：Pearson 0.938 → **0.885**（−0.053），Spearman 0.884 **不变**。线性相关叙述需相应弱化（"极强"→"强"），但"发表与采样高度耦合"的结论不变；秩相关不变说明耦合不是少数异常点造成的。
5. **收入集中**：高收入国家发表份额 70.52 → **75.55%**（+5.03 pp），中高收入 26.10 → 21.31（−4.79 pp）；采样份额 57.60%。收入维度的集中更强，正文"HIC 贡献约七成"类表述需改为"约四分之三"。
6. **人均强度与人口口径（重要）**：人口份额 57.5% → **55.1%**；人均产出强度 28× → **6.6×**（改为"相对世界其余国家"定义；稿件表述"约七倍"）。旧值不可复现，讨论部分"28 倍"的表述必须改，且"少数国家以少人口贡献多数产出"的强度被明显削弱（仍显著）。
7. **九类名单**：HH 26→25（希腊退出），HM 12→11，MH 1→2，MM 39→37，ML 36→33，LM 4→7，LL 77→80；HL/LH 仍为空。SDG 分层份额（11 目标 81.7–89.6%）与九类网络（SI S6）覆盖记录数已按新名单重算；楔子与网络层流量份额仍以 Lead 数值表为准。
8. **分期与残差（已重算）**：分期 HH 份额 93.20% / 88.54%（旧 93.2 / 88.9，趋势不变）；残差五组中位数全部变化（0 组 −0.235、1–5 组 −0.325、6–20 组 +0.477、21–100 组 +0.178、>100 组 −0.151），符号结构不变，1–5 组 95% CI 跨零、>100 组 CI 不含零——"中高产出组正残差、两端负残差"的解读不变，但幅度需按新值改写。
9. **九类网络（SI S6）覆盖记录数（重要）**：因问题类型对 `year <= 2025` 过滤，1,181 条窗外记录无问题类型，五层齐全记录为 **31,964**（旧 SI 写 33,145）；HH 承载 **28,438（89.0%）**（旧 29,560 / 89.2%）。SI 已据此改写，正文若引用网络覆盖率需同步。
10. **档案大类口径变更（重要，发布前用户裁决）**：正式口径改为 **JEV `archive_class` 直接结果**，不再用 18→5 映射。构成由 70.85 / 13.79 / 8.52 / 4.12 / 0.17 / 2.54 改为 **63.47 / 19.57 / 8.81 / 4.84 / 3.01 / 0.30**（Sediment 21,037、Biological growth 6,486、Ice core 2,919、Fossil & shell 1,603、Other natural 999、Unclassified 101）。映射结果降为辅助列 `archive_class_mapped`，18 中类仅用于分层。稿件 §2.1（70.85→63.47、0.17→3.01）、§2.3（71.1/13.7/8.3→63.6/19.6/8.6）、§3.4（2.54%→0.30%）、SI §S4（70.85→63.6）与 SI §S6 方法段已同步。网络子集为 63.63 / 19.63 / 8.56 / 4.94 / 2.95 / 0.30。随之变化：穿透指数 Ice core **+1.50**（旧 +1.64）、Method development **+1.49**（旧 +1.47）；TVD 范围 **0.098–0.118**（旧 0.103–0.120），SDG 层 0.022 不变；SDG 13/11/14 三项检验结果不变（+1.14 pp p=0.071；1.8×/203；−256/p=0.004）。
11. **不变的部分**：语料规模与分期（各期记录数）、SDG 四目标总份额（60.34 / 13.14 / 12.17 / 10.25%）、H1/H2、极地冰芯、PRISMA 链条、阈值 41,458/阶跃 3.96/AIC 289.6 vs 307.7/GAM edf 3.521。
